Story-1. Sign Up functionality:
As a new user, I want to create an account by entering my username, email and password to that I can securely access the application.

Story-2. Login Functionality:
As a registered users I want to log in using my email and password so that I can access my personalized data and features.

Story-3. Home Screen Access:
As a user I want to view a home screen with a logo and navigation options so that I can easily explore the main features of the application.

Story-4. Detail Screen Navigation:
As a user I want to navigate to a detail screen from the home screen so that I can view specific item information clearly.

Story-5. Profile Management:
As a user I want to mark items as favorites and view them in my profile so that I can quickly access the content I care about most.

Story-6. Local storage Persistence:
As a user I want my data to be stored locally so that I can continue using the application even when offline.

Story-7. API Integration:
As a user I want the app to fetch and display data from an external API so that I can access updated information in real time.

Story-8. Settings Menu and Screen:
As a user I want to access a settings menu and screen so that I can configure preferences such as notifications and account options.

Story-9. Notifications:
AS a user I want to receive alerts and configure notifications so that I stay informed about important uupdates within the app.
